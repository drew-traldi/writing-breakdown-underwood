# ✍️ Underwood

Word count, reading and speaking time, readability grade, and your most-used words for anything you write.

**▶ Use it here: [https://drew-traldi.github.io/writing-breakdown-underwood/](https://drew-traldi.github.io/writing-breakdown-underwood/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
